# 프론트엔드 가이드 (어드민 · 뷰어)

어드민(http://localhost:5174)은 해시 라우팅으로 5개 페이지를 제공합니다.
쿼리 파라미터가 붙을 수 있어 **접두사 매칭**입니다 (`#/patch-map?view=moves` 등).

| 해시 | 페이지 |
|---|---|
| `#/` | Router Console (관제 콘솔) |
| `#/patch-map` | ECG Patch Map (평면도 + 동선 타임라인) |
| `#/patches` | 패치 관리 (재고/사용 내역) |
| `#/timelog` | 타임 로그 (시계열/다운타임) |
| `#/appointments` | 예약 목록 (검사/진료) |

딥링크: `#/patch-map?view=moves&tab=planned` (동선 타임라인 특정 탭),
`#/patch-map?report=SA-0001` (환자 리포트 바로 열기), 뷰어 `:5173/?group=<그룹ID>`.

## 1. Top Bar (전 페이지 공통)

- **로고/타이틀** "ECG Channel Router Console" — 클릭 시 콘솔(`#/`)
- **병원선택**: 병원(평면도) 전환. 전환은 **재생성이 아니라 DB 명단 로드** —
  알림에 `DB 명단 N채널 로드 (재생성 없음)` 또는 `DB 비어있음: 신규 생성` 으로 소스가 표기됨
- **중앙관제**: 콘솔 / ECG Patch Map / 패치 관리 / 타임 로그 / 예약 목록
- **테스트**:
  - 채널 +20 / +100 / −20, 초기화 200/500/1000/2000 (수신·송신 카운터 동시 리셋)
  - **시나리오 (건수 1~10 랜덤)**: 패치 교체(SQLite 재고 사용) / 트랜스퍼(병실 이동 +
    구역 간호사 자동 재배정 + 30% 주치의 변경) / 퇴원(채널 폐쇄) / 신규입원
  - **DB 리셋**: 병원별 SQLite 재생성(각 200채널 + 재고 시드) → 에뮬레이터 DB 명단 리로드
    → 라우터 잔재 정리(prune) → 통계 리셋 → **기본 그룹 10개 시딩** 까지 원클릭 체인
- 상태 pill: 라우터 / 분석 서버(연결됨·패스스루) / 채널 수
- **프로파일** (더미 로그인): 화면 템플릿 선택 + 로그아웃

## 2. Router Console (`#/`)

### 시스템 모니터링 카드

- **시스템 리소스** (통합): CPU/메모리/스토리지 — 동일 길이 바 + 수치
  (CPU·메모리 70%↑ 적색, 스토리지 여유 20%↓ 적색), 하단 라우터 프로세스 메모리
- **데이터 I/O** (1칸): ↓수신 / ↑송신 — 누적 + 실시간 속도
- **ECG 패킷**: 누적 + pkt/s, **유실**(seq 갭 감지)은 별도 줄
- **게이트웨이**: 정상 / 전체 배치 (사용 층 기준 동적 계산) + 상태 아이콘 카운트
- **패치**: 상태별 카운트 (정상/이동/약신호/수신중단/해제)
- **가동 시간**: 라우터 가동 + **다운타임 누적** (분석 링크 단절 실측, ms 단위 집계)

### 실시간 이벤트

- 접힘(기본): 최근 3건. 펼치면 최대 100건, 10줄 스크롤
- kind: `analysis_delay` / `analysis_down·up` / `appointment`(예약 등록/이동/복귀) /
  `registry_prune` / `stats_reset` / `display_config`

### 그룹 (리스트형)

- 컬럼: 그룹 이름 / 소속 그룹(ID) / **사용자(주요 사용자)** / 멤버 / 설명(나머지 폭) / 조건 칩 / ✎
- **전 컬럼 양방향 정렬** (헤더 클릭 ▲/▼, 동순위 ID 고정). `all` 은 정렬과 무관하게 최상단 붙박이
- 행 클릭 → 아래 채널 목록을 그 그룹으로 필터
- **사용자 필드 = 주요 사용자**: 담당 간호사/주치의 이름, `W9 전광판`, `수간호사`, `중앙관제` 등
  그 그룹 화면을 실제로 보는 주체 (DB 리셋 시딩이 자동 기입)

### 채널 (테이블)

- **정렬**: 전 컬럼 (상태는 심각도순). **검색**: 이름/채널ID/환자ID.
  **필터 ▾**: 컬럼별 중복 체크 (컬럼 내 OR, 컬럼 간 AND)
- 셀은 **소속 그룹 컬럼만 줄바꿈**, 나머지는 모두 한 줄 고정
- 클릭 → 파형 모달: 환자(단일) / 게이트웨이(GW 전체) / 주치의·간호사(코호트)
- **⇄ 트랜스퍼**: 잔여 병상 병실 드롭다운 + 필드 편집 / 패치 교체(SQLite `in_stock` 재고
  드롭다운 또는 수동 입력) / 퇴원

## 3. ECG Patch Map (`#/patch-map`)

건축 평면도 스타일(벽체·출입문 스윙·계단/엘리베이터 해치·간호스테이션)의 실시간 위치 관제.
도면은 JSON → SVG 벡터 렌더링이라 어떤 크기로도 그려지고, 세로 스크롤이 생기지 않습니다.
건물 전환은 우측 **전층 미니맵**에서 합니다 (별도 A/B동 버튼 없음).

- **층 평면도**: 병실/복도/화장실/검사실에 환자 칩(이름 + ID + 상태 점).
  이동 중 환자는 실제 체류 공간에 나타나고, **병문안 중인 환자는 방문 병실 위치에
  이동(남색) 상태로 표시**됩니다 (입실 아님)
- **게이트웨이 라벨** 클릭 → 그 GW 전체 파형 모달 / **환자 칩** 클릭 → 단일 파형 모달
- **디스플레이(🖥)** 클릭 → 표시 그룹 지정 + "뷰어에서 열기"
- **검색**: 이름/환자ID/채널ID → 해당 층 이동 + 칩 6초 강조
- **전층 미니맵**: 층별 2줄(게이트웨이 사각 / 패치 원형), 사용 층만 표시

### 이동 카드 탭 + 동선 타임라인 (`?view=moves`)

미니맵 최상단의 **"이동 중" 카드**에 이동 환자 수 배지와 패치 아이콘이 표시됩니다.
클릭하면 메인 화면이 동선 타임라인으로 전환됩니다.

- 탭 3개 + **환자 이름 검색**:
  - **이동 중**: 현재 여정 중인 환자 리스트
  - **이동 예정**: 재실/이동 중 환자 가운데 **예약이 잡힌** 사람 (예약 시간순)
  - **동선 기록**: 이동을 마친 환자 (최근 30분, 최신순)
- 행 = 상태 점 + 이름/입원 병실 + 시간대별 체인:
  **과거 이력(최근 4구간, 진입 시각·체류 시간)** → **현재 위치(강조, 경과 시간)** →
  **예약 일정 칩(있을 때만)** — 예약 전엔 "HH:MM:SS 예약", 검사 진행 중엔 **"복귀 예상 HH:MM:SS"**
- 임의 이동(화장실/산책/병문안)은 복귀 시각을 예측할 근거가 없으므로 **복귀 예정을 표시하지 않음**
- "위치 보기 →" 클릭 → 그 환자가 있는 층 평면도로 점프 + 강조

### 파형 모달 공통

- 행 = 메타 3줄 | 스윕 파형 | 심박. 파형 높이 고정 + 진폭 자동 스케일.
  3초 무수신 시 "수신 없음" 오버레이. 카드 크기 고정(플레이스홀더)
- **파형을 클릭하면 환자 리포트가 열립니다** (아래)

## 4. 환자 리포트 모달

파형 모달의 파형 클릭(또는 `#/patch-map?report=<채널ID>`)으로 열립니다.

- **얼굴**: `faces/<profile_no>.png` — 성별/연령 구분되는 아바타 일러스트 (실제 인물 아님)
- **인적사항**: 이름/환자ID/성별·나이/생년월일/혈액형/병실/주치의/담당 간호사/패치·게이트웨이
- **병변·기저질환**: 프로필의 conditions 칩
- **치료 히스토리**: 예약 DB 의 검사/진료 이력 (시간·항목·상태 칩)
- **저장된 파형 — 전문 파형 분석 뷰어** (ECG 모눈/그래프 페이퍼):
  - **개요 스트립**: 전체 저장 구간(8시간 세그먼트)의 min/max 포락선.
    수신 공백(게이트웨이 장애 등)이 빈 구간으로 보임
  - **클릭** = 그 시점부터 15초 상세 / **드래그 블록** = 그 구간 전체 표시
    (120초 초과 블록은 자동으로 min/max 요약 모드)
  - **상세 창**: 기본 최근 15초. **좌우 드래그로 팬**(과거/최신 이동, 저장 범위 클램프),
    ◀ 이전/다음 ▶ 창 단위 점프, "최근 15초" 복귀. 눈금은 구간 길이에 맞춰 자동
    (15초 창 = 굵은 눈금 1초), 시간축 라벨(시작/중간/끝) 표기.
    미수신 구간은 트레이스가 분리되어 끊김이 그대로 보임

## 5. 패치 관리 (`#/patches`)

- 통계 타일: 사용 전(재고) / 사용 중 / 사용됨(폐기)
- **사용 내역** 탭: 최신 사용건이 위 (과거는 아래) / **미사용 재고** 탭
- +100 재고 보충 버튼, 전 컬럼 양방향 정렬

## 6. 타임 로그 (`#/timelog`)

- 범위: 시간(1h)/일(24h)/주(7d)/월(30d) — 서버측 버킷 집계(60초/5분/30분/2시간)
- 차트: ECG 패킷(pkt/s) / 게이트웨이 장애 비중(%) / 패치 채널 수
- **다운타임(분석 링크 단절) 구간은 붉은 음영**, 세로 마커 = 이벤트
  (패치 교체/폐기, 다운타임 시작/종료, 게이트웨이 장애) + 이벤트 타임라인 스트립

## 7. 예약 목록 (`#/appointments`)

- 소스: 에뮬레이터 랜덤 생성 → 라우터 중계 → SQLite (5초 자동 갱신)
- 컬럼: 상태 칩(예약됨/진행 중/완료/취소) / 예약 시간 / 환자 / 구분·항목 /
  장소 / 예상 소요 / **복귀 예상** / 복귀 시각 — 전 컬럼 양방향 정렬
- 예약 시간이 되면 환자가 검사실로 이동하는 시나리오가 자동 실행되고,
  소요 시간이 정해져 있어 복귀 예상 시각이 함께 기록됩니다

## 8. 뷰어 (http://localhost:5173)

- 그룹 드롭다운(기본 `all`) 구독. `?group=<그룹ID>` 로 열면 자동 선택
- **스윕 파형**: 병상 모니터처럼 좌→우 스캐닝, 샘플레이트 페이스 재생, 진폭 자동 스케일
- **자동 밀도**: ≤12채널 상세 / ≤40 컴팩트 / 초과 고밀도 — 메타데이터는 생략 없음
- 부정맥 이벤트 카드 점멸, membership join/leave 로 카드 자동 추가/제거

## 9. 평면도 JSON 스키마 (`web/admin/src/floorplans/*.json`)

파일을 추가하면 **병원선택 메뉴에 자동 등록**됩니다. 에뮬레이터 `patients.py` 의
`HOSPITALS` 에 같은 id 로 구조(건물/층/병실/병상/프리픽스)를 정의해야 연동됩니다.

```jsonc
{
  "id": "seoul-a",            // 에뮬레이터 HOSPITALS 키와 일치
  "name": "서울 A 병원",
  "order": 1,                 // 메뉴 정렬
  "bedsPerRoom": 6,           // 병실당 병상 (트랜스퍼 잔여 병상 계산)
  "viewBox": { "w": 1400, "h": 760 },
  "buildings": ["A", "B"],
  "floors": [15, 14, ..., 2, 1],   // 최대 확장 층 (사용 층만 표시됨)
  "plans": {
    "default": { "spaces": [ ... ] },  // 일반 병동층
    "1":       { "spaces": [ ... ] }   // 층 번호 키로 특정 층 전용 도면
  }
}
```

### space 오브젝트

```jsonc
{
  "id": "room-01",
  "type": "room",                    // 아래 표 참조
  "label": "{f}01호",                // {b}=건물, {f}=층 치환
  "rect": { "x": 10, "y": 10, "w": 163, "h": 270 },
  "door": "N|S|E|W",                 // 출입문 방향 (개구부 + 스윙 호)
  "gw": "GW-{b}{f}-{f}01",           // 게이트웨이 (있으면 상태 아이콘/클릭 모달)
  "match": { "kind": "ROOM|HALL|WC|EXAM", "room": "{f}01", "zone": "Z1" }, // 환자 배치 판정
  "fill": "#f6e7a5",                 // facility 전용 색
  "display": "DISP-{b}{f}-ST",       // display 전용: 디스플레이 ID
  "compact": true                    // 좁은 공간용 오버레이 축소
}
```

| type | 렌더링 | 용도 |
|---|---|---|
| `room` | 벽 + 출입문 스윙, 재실 시 틴트 | 병실/화장실/검사실 (gw+match 로 환자 표시) |
| `zone` | 투명 (장애 시 적색 틴트) | 복도 구역 (HALL 게이트웨이 + 이동 환자 칩) |
| `corridor` / `open` | 회색 바닥 | 복도 바닥 / 로비 등 개방 공간 |
| `stairs` | 사선 해치 | 계단 |
| `elevator` | 크로스 해치 + 문 표시 | 엘리베이터 |
| `station` | 진회색 솔리드 | 간호스테이션 |
| `facility` | `fill` 색 + 벽 | 처치/준비실, 직원 라운지, 설비 등 |
| `display` | 모니터 아이콘 (클릭 = 그룹 지정) | 벽걸이 디스플레이 |
| `entrance` | 외벽 개구부 + 양문 스윙 | 주출입구 |

## 10. 화면 템플릿 (`web/admin/src/templates/*.js`)

파일을 추가하면 프로파일 메뉴의 템플릿 목록에 자동 등록됩니다. localStorage 유지,
`?tpl=<id>` 로도 지정 가능.

```js
export default {
  id: 'midnight-monitor',
  name: '미드나이트 모니터',
  description: '어두운 관제실 톤',
  order: 2,
  layout: {                       // 색상뿐 아니라 레이아웃도 제어
    showStats: true,              // 시스템 모니터링 카드 표시
    showEvents: true,             // 실시간 이벤트 표시
    eventsPosition: 'top',        // 'top' | 'afterChannels'
  },
  vars: { '--bg': '#0a1120', ... },  // styles.css 의 :root 토큰 오버라이드
  css: 'body { color-scheme: dark; }', // 추가 CSS
}
```

기본 3종: 클리니컬 라이트(기본) / 미드나이트 모니터 / 서지컬 민트(통계 숨김 + 이벤트 하단).

## 11. 타이포그래피/디자인 규칙

- 타입 스케일 6단계 (`--fs-xs` 11px ~ `--fs-xl` 22px), 숫자는 tabular-nums
- 상태·게이트웨이는 색+모양(원/사각)+텍스트 라벨 삼중 구분 (색맹 안전)
- 파형 뷰어(리포트)는 클래식 ECG 용지 컨벤션: 밝은 종이 + 2단계 격자 + 진한 잉크 트레이스
- 도면 범례: HALL&CORRIDOR / ELEVATOR / NURSE STATION / STAIR
